bioseq::io::sequence_batch

A batch of records delivered to the user's handler.

A batch of records delivered to the user's handler. It holds three shared buffers (_header_storage, _sequence_storage, _quality_storage) and per-record offset / metadata arrays. This eliminates per-record std::string + std::vector<uint64_t> allocations that dominated short-read throughput.

The accessors header(i) / sequence(i) / quality(i) return non-owning views (std::string_view, compact_sequence_view<p_range>, std::span<const std::uint8_t>) into the batch's shared storage. Returned views remain valid as long as the batch.
